## Project Overview

HVAC controller firmware for PIC32CM6408PL10032 (Cortex-M0+) microcontroller. Uses MPLAB X with XC32 toolchain v6.00, CMake/Ninja build system, and Microchip Code Configurator (MCC) for peripheral setup.

## Build Commands

```bash
# Configure (from firmware directory)
cmake --preset HVAC_default_conf -S cmake/HVAC/default

# Build
cmake --build _build/HVAC/default

# Clean and rebuild
cmake --build _build/HVAC/default --clean-first
```

Output: `firmware/out/HVAC/default.elf`

## Directory Structure

- `firmware/config.mcc/src/` - Application source code
  - `main.c` - Entry point, timer setup, main loop
  - `seven_seg.c/h` - 7-segment display driver (multiplexed, 2-digit)
  - `segment_pins.c/h` - Low-level pin control for segments
  - `config/default/` - MCC-generated peripheral libraries (PLIB)
  - `packs/` - Device family packs (DFP) and CMSIS headers
- `firmware/_build/` - CMake build output (can delete)
- `firmware/cmake/` - Generated CMake files
- `hardware/` - PCB documentation, pinmapping

## Hardware Architecture

- **Target**: PIC32CM6408PL10032 @ 24MHz
- **Display**: 2-digit common-anode 7-segment, multiplexed via TC0 timer at 4ms
  - COM1_AL (PA23) = right digit (units)
  - COM2_AL (PA06) = left digit (tens)
  - Segments A-G, DP on PORT_GROUP_0 (various PA pins)
  - Common anode: LOW = segment ON, HIGH = segment OFF
- **LED_T**: Status LED on PA26

## MCC-Generated Code

Files under `config/default/` are generated by MPLAB Code Configurator. Pin macros (e.g., `COM1_AL_Set()`, `LED_T_Toggle()`) are defined in `peripheral/port/plib_port.h`. To change pin configurations, use MCC rather than editing these files directly.

## Peripheral Usage

- **TC0**: Timer/Counter 0 in 16-bit mode, 4ms period (1MHz clock / 4000 ticks). Drives display multiplexing via `SevenSeg_Refresh()` callback.
- **PORT**: GPIO control via PLIB macros and `PORT_Group*` functions
