## Project Overview

HVAC controller firmware for PIC32CM6408PL10032 (Cortex-M0+) microcontroller. Uses MPLAB X with XC32 toolchain v6.00, CMake/Ninja build system, and Microchip Code Configurator (MCC) for peripheral setup.

## Build Commands

```bash
# Configure (from firmware directory)
cmake --preset HVAC_default_conf -S cmake/HVAC/default

# Build
cmake --build _build/HVAC/default

# Clean and rebuild
cmake --build _build/HVAC/default --clean-first
```

Output: `firmware/out/HVAC/default.elf`

## Hardware Architecture

- **Target**: PIC32CM6408PL10032 @ 24MHz
- **Display**: 2-digit common-anode 7-segment, multiplexed via TC0 timer
  - COM1_AL (PA23) = right digit (units), COM2_AL (PA06) = left digit (tens)
  - Segments A-G, DP on PORT_GROUP_0; common anode: LOW = segment ON
- **LED_T**: Status LED on PA26
- **Switches**: 7 switches (S1-S7) share segment pins B-G and DP; scanned by temporarily switching segment pins to input with pullup

## Timer Architecture

TC0 drives all periodic tasks via a 6ms tick (period = 5999 at 1MHz). The `TC0_Callback` handles:
- **Display multiplexing**: `SevenSeg_Refresh()` every 6ms (alternates digits)
- **Switch scanning**: Sets flag every 24ms (4 ticks); `Switch_Scan()` runs in main loop
- **Application timing**: 1-second flag (~167 ticks)

## Code Patterns

**Shared Segment/Switch Pins**: Segment pins double as switch inputs. `Switch_Scan()` temporarily reconfigures pins to input with pullup, reads state, then display refresh restores output mode. Must turn off COM1/COM2 during scan.

**Peripheral Access**: Use PLIB macros from `plib_port.h` for pin control (`COM1_AL_Set()`, `LED_T_Toggle()`). Direct register access via `PORT_REGS->GROUP[0]` for bulk operations in `switch.c` and `segment_pins.c`.

## MCC-Generated Code

Files under `config/default/` are generated by MPLAB Code Configurator. To change pin configurations, use MCC rather than editing these files directly.

## Key Files

- `main.c` - Entry point, timer callback with tick management, main loop
- `seven_seg.c/h` - Display driver with multiplexing
- `switch.c/h` - Switch scanning with debounce
- `segment_pins.c/h` - Low-level pin direction control for shared pins
